### 02 — Flex Technology Group: Multi-Site Print Fleet TCO & Scenario Model
Originally built and delivered to CFOs, CIOs, and COOs — analyzing device usage,
vendor fragmentation, and cost-per-click data to produce TCO models and deployment
scenario recommendations. Rebuilt with synthetic data comparing a fragmented
16-device current state vs. a consolidated 6-device Flex proposal across 5 sites.

**Headline result:** 16 → 6 devices · 4 vendors → 1 · $116K saved over 3 years · 49% cost reduction

**Tools:** Tableau Public · MySQL · Excel
**Live dashboard:** https://public.tableau.com/app/profile/colin.moral/viz/Multi-SitePrintFleetTCOModel/Dashboard1
