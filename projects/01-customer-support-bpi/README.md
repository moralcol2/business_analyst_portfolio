# Project 01 — Customer Support Process Analysis

**Domain:** Business Process Improvement  
**Tools:** Excel, Power BI  
**Status:** In Progress  
**Dataset:** [Customer Support Ticket Dataset — Kaggle](https://www.kaggle.com/datasets/suraj520/customer-support-ticket-dataset)

---

## Business Question
Why are certain support tickets taking significantly longer to resolve, and what operational changes would reduce average handle time?

## Approach
1. Downloaded and cleaned raw ticket data in Excel
2. Built pivot tables to identify resolution time patterns by ticket type, channel, and priority
3. Correlated resolution time with customer satisfaction scores to quantify business impact
4. Visualized findings in Power BI dashboard
5. Produced a one-page recommendation report

## Key Files
| File | Description |
|------|-------------|
| `data/raw/` | Original unmodified Kaggle CSV |
| `data/cleaned/` | Cleaned Excel workbook with pivot analysis |
| `dashboard/` | Power BI .pbix file + exported PNG screenshots |
| `report/findings.md` | Root cause findings and recommendations |
